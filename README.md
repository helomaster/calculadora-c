# 🧮 Calculadora em C
- Este projeto trata de uma calculadora em código C que funciona pelo terminal. 
- Tem como objetivos praticar o básico em C e o básico em disponibilização de repositórios aqui no Github.

Apresentação visual do Projeto:

## 🛠️ Pré-Requisitos
- Instale por aqui a sua versão do código;
- Para rodar, é necessário que sua máquina tenha um compilador C (como o gcc)
- Também é necessário um terminal ou prompt de comando;

## 🧪 Exemplos de Comando
_Aqui estão as funcionalidades que você pode explorar: _

- Adição de dois números;
- Subtração de dois números;
- Multiplicação de dois números;
- Divisão de dois números (com verificação para divisões por 0);
- Repetição de qualuqer operação de acordo com a vontade do usuário;
- Interface amigável no terminal;

## 📦 Instalação | Lunix/Windows(Com WSL):

**Linux(Ubuntu/Debian):**
```
sudo apt update
sudo apt install gcc
```

**Windows:**

- Instale o WSL + Ubuntu;
- Ou use compilador gcc do MinGW ou Cygwyn;
- Ou compile diretamente pelo VSCode com a extensão C/C++.


## 🆗 Execução:
Se estiver usando o _gcc_ no terminal: 
```
gcc calculadora.c -o calculadora
./calculadora
```
Agora, se estiver usando o _VSCode_:

1. Abra o projeto pelo VSCode;
2. Tenha certeza de que a extensão C/C++ esteja instalada;
3. Compile e execute usando o terminal integrado ou um task.
